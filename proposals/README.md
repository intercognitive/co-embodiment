# Proposals

This directory is for working drafts that may later become IOSPs.

A proposal here is not an Intercognitive Open Standard. It is a structured draft for discussion.

## Suggested Draft Template

```markdown
# Draft: Embodied Capability Manifest

## Summary

A machine-readable manifest for sensors, actuators, spatial context, permissions, safety limits, and services exposed by embodied infrastructure.

## Problem

What interoperability problem does this solve?

## Scope

What is included?

## Non-Goals

What is explicitly out of scope?

## Proposed Model

Describe the interface, schema, protocol, or process.

## Security, Privacy, and Safety

What can go wrong? What must implementers protect?

## Implementers

Who is interested in implementing or testing this?

## Open Questions

What is unresolved?
```

## Candidate Proposal Areas

- Embodied capability manifest
- Shared sensor access protocol
- Spatial context package
- Agent permission and arbitration model
- Robot-as-infrastructure discovery
- Observation and action audit log
